# AF Furniture - Admin Panel

Admin panel for managing products, categories, banners, and enquiries for a modern furniture catalogue platform.

## Tech Stack

- **Frontend:** React 19 + Vite
- **Routing:** React Router v7
- **Linting:** oxlint

## Project Structure

```
├── admin-panel/
│   ├── src/
│   │   ├── components/   # Header, Sidebar
│   │   ├── pages/        # Dashboard, Login, ProductList, Categories, etc.
│   │   ├── App.jsx
│   │   └── main.jsx
│   ├── public/
│   └── package.json
├── overview.md           # Project proposal
├── adminpanel.md         # Project proposal (OCR draft)
└── README.md
```

## Getting Started

```bash
cd admin-panel
npm install
npm run dev
```

## Available Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Start dev server |
| `npm run build` | Production build |
| `npm run preview` | Preview production build |
| `npm run lint` | Lint with oxlint |

## Branches

- `master` — main branch
